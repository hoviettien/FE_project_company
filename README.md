# 💬 Tích hợp n8n Chat Widget vào Frontend

Hướng dẫn nhúng **n8n Chat** vào website frontend để người dùng có thể tương tác trực tiếp với workflow đã cấu hình trong n8n.

---

🚀 Cách thực hiện
Mở tài liệu n8n
Vào Docs → Chat Widget
 để tham khảo phần hướng dẫn nhúng.
 
Copy đoạn mã CDN Embed
n8n cung cấp sẵn đoạn <link> và <script> để tích hợp.

Gắn vào file index.html
Thêm vào trước thẻ </body> của file index.html, đồng thời thay YOUR_PRODUCTION_WEBHOOK_URL bằng URL webhook thật từ n8n.
